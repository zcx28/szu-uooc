关于项目使用的说明

本项目是我出于编程学习与技术探索开发的个人项目，仅供学习交流与经授权的安全研究。

我不鼓励任何利用脚本代替本人完成课程学习、测验、签到等违反学校及平台规定的行为，也不支持将本项目用于此类用途。

如发现平台安全问题，请通过学校及平台的正式渠道反馈；希望学校与平台持续完善安全机制、及时修复相关问题。

请大家遵守学校及课程平台的相关规定，合理使用技术。

把 ZIP 整个解压，双击「启动-Windows.cmd」或「启动-Mac.command」。
Linux x86_64 桌面系统：在完整解压的文件夹打开终端，运行 bash ./启动‑Linux.command；首次自动下载并校验运行环境和组件，请保持联网。
首次启动自动下载组件。按页面的新手指引选择并连接 Chrome、Edge 或 Firefox，读取全部课程。不会填 API 时可点「先不填，免费开始」，也可设置 AI 解题服务。
免费模式优先题库和缓存；缺题的选择、判断题随机作答并自动提交，可能答错，不保证通过。图片题和缺答案的填空等题型请手动完成测验后继续。免费模式不调用解题服务，随机答案不保存到题库。设置中可以切换答题方式。
Chrome / Edge 调试连接：点「复制调试页地址」，粘贴到所选浏览器地址栏并回车，开启该页的 Allow remote debugging，再回控制台连接并允许所选浏览器的连接请求。
点一门课旁的「开始」，程序自动继续整门课的视频与章节测验，一次只运行一门。
暂停后可「继续」本课，或「停止」后换课；完成后手动开始下一门。
使用 Chrome / Edge 时，学习和原生智能验证连接原来已登录的所选浏览器。
Firefox 在 Windows、macOS、Linux 上均使用独立自动化窗口：首次连接按需下载配套组件，并尝试从默认资料导入优课网及学校的持久化 Cookie 和临时登录会话；多资料用户请先确认默认资料是所需账号。若未登录，请在此窗口登录。不会把其他网站的 Cookie、密码文件或网站存储复制到自动化资料；以后重连保留此窗口自己的登录与交卷记录，退出登录后不会重新覆盖。Firefox 智能验证请本人手动完成；Linux 暂不支持应用内开机自启动。
程序自动点原生验证复选框；若出现额外挑战，点「去验证」在课程窗口接管。
网站提示验证失败时自动等待重试，间隔从 5 秒逐步延长至 30 秒，复用已填答案，不重复请求解题。人工验证通过后保持窗口，程序自动继续提交和后续任务，无需再点「继续」。主动暂停或停止会取消待重试操作。

备用导入：点「粘贴网址」。打开课程 → 进入学习 → 复制完整网址，每行一个。
视频页网址也可以：程序读取整门课目录，继续后续视频和测验，完成情况以网站目录为准。

每天签到：设置 → 每日签到，选择课程和已登录的所选浏览器 资料，核对账号，按提示更新兼容脚本。
开启自动签到和「登录电脑后自动启动程序」。默认启动立即打开全部所选课程，同一天不重复。
签到无需解题 Key，也无需每天授权浏览器调试。「今日已打开」仅记录打开命令，签到结果在网站核对。

AI 解题：设置 → 解题服务，只填 API 网址和 API Key，点击「检测并保存」。程序筛选并测试模型，最多再选择一个主要模型。检测可能产生少量费用，本次最多 $0.02；没有可核实价格时阻止付费调用。默认保留原中转站网址；OpenAI、DeepSeek 官方和部分兼容服务可用，不能保证任意网址可用。每门课最高 $1，费用及未知费用预留在课程「更多操作」里查看；显示上限估算时，以服务商实际账单为准。图片题不可用时会暂停，需手动完成或修改服务。
关闭网页后程序继续运行；设置 → 退出程序，会停止学习和签到。
请保留程序文件夹；移动后重新保存自启动设置。

更换浏览器：设置 → 学习浏览器。先停止课程，等待解题请求和签到结束；重新核对账号、读取课程并测试签到资料。只支持同一课程账号，课程和费用共用，当天签到不因更换浏览器重复打开。

遇到问题时：按课程旁或设置里的文字操作，做完后点「继续」。提示会留在页面上，不用赶着截图。
需要核对扣费时，先去购买解题服务的网站查看账单；需要核对交卷时，先打开课程查看提交结果，再继续。
如果页面让你联系帮忙安装的人，请把提示截图发给他，不要自行删除课程、设置或费用记录。
